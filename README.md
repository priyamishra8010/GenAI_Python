                                                               ** AI Text Summarizer**
**Project Overview**
An AI-powered text summarization application built using Python, Streamlit, LangChain, and Groq LLMs.

**Features**
•	Accepts user text through a simple web interface.
•	Uses a large language model to generate summaries.
•	Displays the generated summary in the Streamlit application.

**Technologies Used**
•	Python
•	Streamlit
•	LangChain
•	Groq API
•	Python dotenv

**How to Run what description**
1.	Install dependencies: pip install -r requirements.txt
2.	Create a .env file and add your Groq API key as GROQ_API_KEY=your_api_key.
3.	Run the application: streamlit run app.py
